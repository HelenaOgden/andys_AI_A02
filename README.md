Note the program requires archive.zip to be present in the current directory rather than the 3 individual zip files here in GitHub. These were created because the archive.zip file was too big to upload.

Either archive.zip should be recreated from the individual zip files or download it from: https://www.kaggle.com/datasets/adharasaniveekshitha/golden-retriever-emotion-recognition-dataset


The Alg2_results.jpg file doesn't match the one shown in the Alg2 Juypter workbook because the program produces different results each time it is run.  The Alg2 workbook in GitHub was run at a different time compared to the output files and thus has this difference. 

The report does use the Alg2_results.jpg result file for the calculations. The data augmentation phase has random rotations, flips and resizing which cause the difference.
